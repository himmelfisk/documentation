# Changelog

## v1.0.0 — 2026-03-28

First stable release. All core capture features are working on both Android and iOS.

### Features

- **Photo capture** — Take documentation photos using the device camera
- **EXIF metadata** — Extract and display photo details (camera model, exposure, etc.)
- **GPS geotagging** — Automatic location tagging from photo EXIF or device GPS fallback
- **Map link** — One-tap link to view the photo location in Google Maps
- **Microsoft login** — Authentication via Azure AD with MSAL redirect flow
- **Multilingual UI** — Norwegian (default) and English
- **Dark mode** — Automatic support via system preference
- **Cross-platform** — Android and iOS via Capacitor 8
